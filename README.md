# AlgoLab

AlgoLab is an interactive data-structures-and-algorithms learning platform inspired by the workflow of modern DSA visualizers.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## What is included

- Searchable DSA curriculum grouped by category and sub-section
- Array searching and sorting visualizers with custom input
- Play, pause, previous, next, reset, randomize, and speed controls
- Live algorithm messages and variable state
- Stack push/pop/peek/is-empty playground
- Queue enqueue/dequeue/peek/is-empty playground
- Linked-list pointer playground
- Binary-tree playground
- Graph traversal playground
- Detailed lesson explanations and implementation steps
- Properly formatted multi-line TypeScript code with line numbers
- Complexity reference and interview notes
- Responsive mobile navigation

## Design goal

Every module uses the same learning flow: see the state change, understand the operation, read the implementation, then reason about complexity.

## Implementation languages

Every lesson's Implementation panel supports five languages:

- TypeScript
- JavaScript
- Python
- Java
- C++

The language tabs switch the displayed implementation without changing the visualizer state. Code is rendered as separate lines with line numbers and includes a copy button.


## Expanded curriculum

AlgoLab includes an expanded DSA curriculum covering arrays and vector operations, sorting and searching, linked lists, stacks and queues, hash tables/sets/maps, heaps and priority queues, trees, graphs, shortest paths, minimum spanning trees, maximum flow, dynamic programming, greedy algorithms, string algorithms, interview patterns, and time-complexity lessons.

The Implementation panel supports TypeScript, JavaScript, Python, Java, and C++ with separate readable source for the supported modules.
